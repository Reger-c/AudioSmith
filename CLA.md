## 10. How to sign

You sign this Agreement on GitHub, once, for all Your Contributions:

1. Open a pull request to https://github.com/hehehai/AudioSmith.
2. The CLA bot comments on it with a link to this document. Read it.
3. Post a comment on the pull request with exactly this sentence:

   > I have read the CLA Document and I hereby sign the CLA

The bot records Your GitHub user name and account ID, the pull request and the date in the Project's signature file, which is public. Every author of the commits in a pull request signs; commits must be linked to a GitHub account (use an e-mail address registered with Your account). The signature covers Your past and future Contributions until a new version of this Agreement asks You to sign again; earlier Contributions stay under the version You signed.
